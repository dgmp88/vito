# Vito (web)

A tiny **voice-in, text/document-out** assistant in the browser. You talk, a
realtime voice model handles the conversation and makes quick edits to a
markdown document, and anything that needs real thought goes to a stronger
"expert" model that edits the document or replies in text.

## How it works

- Sign in, then start a live voice session and talk naturally. You can
  interrupt Vito at any time.
- Highlight text in the document to scope what you're asking about.
- The voice model keeps its replies short. It makes small edits itself and
  hands anything harder to the expert model, which acts only through tool calls
  (edit the document, rewrite it, or reply in the transcript).
- Each conversation is an append-only log plus its current document, stored per
  user. Model usage and cost are recorded per call.

## Stack

- **SolidStart** (Solid + Vite, server functions), TypeScript
- **Gemini** via `@google/genai`: the Live API for voice (browser ↔ Google over
  WebSocket, using ephemeral tokens minted on the server) and a standard model
  for the expert, streamed from the server
- **Neon Auth** for sign-in; server functions verify the session JWT
- **Neon Postgres** via Kysely, with types generated by kysely-codegen

The Gemini API key stays on the server.

## Running

```bash
npm install
cp .env.example .env   # set GEMINI_API_KEY, VITE_NEON_AUTH_URL, DATABASE_URL
npm run db:migrate     # apply migrations and regenerate DB types
npm run dev            # http://localhost:3000
```

See `package.json` for other scripts and `.env.example` for optional settings.

> The mic needs a secure context (`localhost` or HTTPS). Use headphones if
> speaker bleed makes Vito interrupt itself.

## Where things live

- `src/routes/`, `src/components/`: UI
- `src/lib/`: client and server logic (Live client, expert agent, prompts,
  store and sync, auth, pricing)
- `migrations/`: database schema
